# Requesting New Software

Employees cannot install software on company laptops on their own.

1. Open the service portal and choose "Request software".
2. Name the program, the version, and why you need it.
3. Your manager approves the request.
4. IT installs the program within 3 working days, or tells you if it is not allowed.

Free tools are not exempt from this rule. Do not download installers from the internet.
