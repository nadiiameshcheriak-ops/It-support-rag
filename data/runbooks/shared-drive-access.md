# Getting Access to the Shared Drive

The team shared drive is mapped as drive S: on company laptops.

1. Connect to the office network or to the VPN.
2. Open File Explorer and look for drive S: in "This PC".
3. If it is not there, enter \\fileserver\teams in the address bar.

If you see "Access denied", you need permission for that folder. Ask your manager to send an access request to the service desk, naming the exact folder.
