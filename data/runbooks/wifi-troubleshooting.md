# Wi-Fi Is Connected but There Is No Internet

1. Turn Wi-Fi off and on again.
2. Forget the network and connect again.
3. Restart the laptop.
4. Check whether other devices nearby have the same problem. If they do, report it to the service desk, as it is probably a network issue.
5. If only your laptop is affected, run the network troubleshooter in Settings > Network & Internet.

If the problem remains, contact the service desk with the exact error message and the room where you are.
