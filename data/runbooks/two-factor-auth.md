# Setting Up Two-Factor Authentication (2FA)

All company accounts require 2FA.

1. Install the "Authenticator" app on your phone.
2. Sign in to the security page at security.example-corp.com.
3. Choose "Add sign-in method" and select "Authenticator app".
4. Scan the QR code with the app.
5. Enter the 6-digit code shown in the app to confirm.

If you get a new phone, set up 2FA again before wiping the old one. If you already lost access, contact the service desk.
