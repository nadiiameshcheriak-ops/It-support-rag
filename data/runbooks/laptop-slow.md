# Laptop Is Running Slowly

1. Restart the laptop. Many slowdowns appear after weeks without a restart.
2. Close programs and browser tabs you do not use.
3. Open Task Manager (Ctrl + Shift + Esc) and check which program uses the most CPU or memory.
4. Check free disk space. If less than 10% is free, delete large files or move them to the shared drive.
5. Install pending Windows updates and restart.

If the laptop is still slow after these steps, open a ticket and mention which program uses the most resources.
